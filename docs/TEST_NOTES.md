# Test Notes: selectable agent CLIs

_Generated by: Claude Code | 2026-10-02_

## Scope

This change makes the CLI that runs each phase configurable:
- `agents.json` defines each CLI and the default phase mapping.
- `loop assign` sets a per-project mapping.
- `run --agent` / `run_now.ps1 -Agent` override the agent for a single run.
- Prompt fallback: a phase prompt is shared by every agent unless an agent has its own.

These notes cover the dry-run, regression and **real-CLI smoke tests** run for that change.

## 3. Real-CLI smoke test

Script: `tests/smoke_agents.py`. Each agent runs through the real `Runner`, all agents in parallel, 300s timeout each.

Each agent must do three things:
1. **MEDIA_READ**: read a random token from `media dir/media_token.txt`.
2. **WRITTEN**: write `smoke proj/smoke_out/<agent>.txt`.
3. **PROMPT_INTACT**: put the random PROMPT TOKEN from the **last line** of the multi-line prompt on line 2 of that file. This proves the prompt was not truncated.

## Findings and notes

1. **claude cannot create new files headless with the original `--allowedTools Read,Edit,Bash`.** It refuses rather than falling back to Bash. Phase 02 normally has to create `tasks/02_implement/implementation_notes.md` and often new source files.
   - **Open decision for the owner:** add `Write` to claude's `--allowedTools` in `agents.json`. The `Read,Edit,Write,Bash` variant passed.
2. **agy and relative paths:** keep prompts on absolute `{{WORKSPACE}}` paths. A relative path can land in the media dir when the project has `media`.
3. **copilot:** `copilot.BAT` runs `powershell copilot.ps1` without `-NoProfile`, so the user's PowerShell profile prints `fnm : The term 'fnm' is not recognized` to stderr. This is harmless; the run still passed.
4. **Multi-line prompts and `.bat`/`.ps1` wrappers:** a CLI that is only reachable through such a wrapper must use `prompt_mode` `pointer` or `file`. Otherwise the orchestrator refuses the run (exit 1) rather than truncating the prompt.
5. The smoke test proves the **invocation** works: flags, auto-approve, prompt delivery, media access, exit within the timeout. It does **not** judge how well each model performs a real phase.
